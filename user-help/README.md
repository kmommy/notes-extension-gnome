# Basic help manual

## Using the extension

**Show/hide all notes:** click on the icon in the GNOME Shell top bar.

**Create a note:** click on the "+" button at the left of a note header, it will create a new note, with the same color and the same font size as the note you clicked on.

![](./help_picture_1.png)

**Move a note:** drag the blank space in the center of the note header.

**Resize a note:** drag the corner in the lower-right of the note.

**Delete a note:** click on the wastebasket icon and confirm. A notification lets you undo the deletion.

**Hide a single note:** click on the eye icon. Right-click the icon in the top bar to show it again.

**Find a note:** right-click the icon in the top bar and type in the search field. Press Enter to open the first result.

The notes that were visible when you logged out (or locked the screen) are shown again automatically.

## Tasks

**Create a task:** click on the checkbox button in the note header, or press Ctrl+T. The current line starts with a box (☐).

**Check a task:** click on its box (☑). Click again to uncheck it.

Pressing Enter in a task creates a new task below it. Pressing Enter in an empty task ends the list. Shift+Enter inserts a regular line break.

**Remove checked tasks:** click on the menu button and select "Remove checked tasks".

## Keyboard shortcuts in a note

| Shortcut | Action |
|----------|--------|
| Ctrl+T | Turn the current line into a task, or back into text |
| Ctrl+Plus / Ctrl+Minus | Increase / decrease the font size |
| Escape | Stop typing in the note |

## Customizing notes

**Change color:** click on the menu button, and select a color.

The "Custom color" submenu lets you type a color in hexadecimal, such as `#f9f06b`.

![](./help_picture_2.png)

**Change font size:** click on the menu button, and increase or decrease the font size with "+" and "-" buttons.

**Title:** click on the menu button and select "Edit title". The title is shown in the note header and in the menus. Leave it empty to remove it.

**Pin a note:** click on the menu button and turn on "Show in the top bar and overview". The text of the note then scrolls next to the icon in the top bar, and the note is shown as a card in the upper-left corner of the overview (Super key); clicking the card shows the note. Each place can be turned off in the settings window.

**Advanced settings:** click on the "Settings" menu item to access the settings dialog.

## The settings window

The settings dialog window provides several options:

**Position of notes:** select whether you want the notes to be shown above the windows or underneath them.

**Automatic focus:** if this is enabled, the notes will automatically get the keyboard focus when you hover them with the mouse pointer.

**Keyboard shortcut:** hide/show notes with a keyboard shortcut. If this is enabled, the icon in the top bar can be hidden.
